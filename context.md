# Answer Evaluation Guidelines

## Scoring Criteria (0-10 points)

1. Accuracy (0-4 points)
   - 4 points: Completely accurate and precise
   - 3 points: Mostly accurate with minor inaccuracies
   - 2 points: Partially accurate with some errors
   - 1 point: Contains some correct elements
   - 0 points: Completely incorrect

2. Completeness (0-3 points)
   - 3 points: Covers all important aspects
   - 2 points: Covers most important aspects
   - 1 point: Covers some important aspects
   - 0 points: Missing key elements

3. Clarity (0-3 points)
   - 3 points: Clear, well-structured, and easy to understand
   - 2 points: Generally clear with minor issues
   - 1 point: Somewhat unclear or poorly structured
   - 0 points: Unclear or confusing

## Evaluation Process
1. Read the question carefully
2. Compare the answer against the expected response
3. Evaluate each criterion (Accuracy, Completeness, Clarity)
4. Sum up the points
5. Provide a brief explanation for the score

## Response Format
The evaluation should be in the following format:
Score: X/10
Explanation: [Brief explanation of the score]
